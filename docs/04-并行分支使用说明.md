# HelpWork 并行分支使用说明

本说明适用于 HelpWork v1.1（数据库 schema v2）。并行分支用于“若干子流程并行推进，全部完成后主线再继续”，不是条件选择或自由流程图。

## 创建分支

1. 在中栏选中或右键已有步骤。
2. 选择「在此创建并行分支…」。
3. 输入分支数量（至少 2 条），分别填写名称，点击「创建」。每条分支会自动生成一个根步骤，标题默认为“分支名 · 开始”。
4. 分叉点行显示“并行 k/N”。点击该按钮或顶部“展开”查看分支树；右键节点可在主线/分支节点上再次创建分支，支持嵌套。

## 在分支里记录

- 在分支标题栏点击「＋ 步骤」继续记录该分支；也可选中分支步骤后右键重命名、上移、下移或删除。
- 每条分支按自己的顺序编号和排序，互不串线。步骤标题、备注和附件沿用原节点操作。
- 分支标题栏右键可重命名或删除分支。
- 已标记完成的分支不能继续追加步骤或展开新的嵌套分支；先点「✓ 已完成」取消标记，再继续记录。现有步骤的标题、备注、附件仍可编辑。

## 完成分支与主线门控

- 在分支标题栏点击「进行中」即可显式标记「已完成」；状态会立即变成绿色“✓ 已完成”，并有提示。点击完成状态可撤销。
- 外层分支中仍有未完成的嵌套分支时，不允许把外层分支标为完成，提示会列出未完成的嵌套分支。
- 分叉点下只要还有任一条未完成分支，主线「＋ 添加节点」就会禁用；顶部提示会列出分叉点及尚未完成的分支名。全部完成后主线按钮恢复。
- 分支内部同样有门控：内层分支未完成时，该外层分支暂不能继续追加步骤。
- 取消任意分支的完成标记会重新锁住对应汇合点后面的主线/父分支继续操作。

## 当前路径、收起和末端

- 当前选中项在树中高亮，详情栏显示“当前位置”路径；分叉点可以逐个展开/折叠，也可以用顶部“展开/折叠”。
- 主线末端和所有未完成分支的末端显示“末端”标记。
- 含分支流程的最近选中节点保存在本机界面状态（localStorage），重启后恢复；记录本身、状态和结构保存在 SQLite 数据库中。
- 无分支流程继续以原来的平铺主线显示，编号、拖拽排序与添加步骤行为保持不变。

## 删除与回收站

- 删除分支前会弹出明确确认，说明分支步骤数；其嵌套分支、节点和附件一起进入回收站。取消确认不执行删除。
- 分叉点节点下仍有分支时不能直接删除该节点；先删除分支（或按需处理子分支），以免产生孤儿。
- 删除分支后，回收站以“并行分支”整体条目呈现；还原会恢复该分支与同批删除的嵌套结构。彻底删除会清理该分支节点和附件引用。
- 单独还原分支节点时，若所属分支已不存在/已删除，则安全回落为主线节点，避免孤儿引用。

## 导出与导入

- 纯线性流程仍导出 v1 格式。
- 有并行分支的流程导出 v2 格式，包含分支名称、分叉点、顺序、完成状态和嵌套关系。
- 旧 v1 包可正常导入并成为单主线；v2 包导入时会重新映射内部 ID，同时保留结构和未知扩展字段。

更多结构字段与回滚方式见 [数据结构说明](./05-并行分支数据结构说明.md)；限制和取舍见 [已知限制](./06-并行分支已知限制.md)。
