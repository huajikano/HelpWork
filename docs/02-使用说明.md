# HelpWork 使用说明

> 面向非程序员的操作手册。HelpWork 是一个「工作流档案柜」：把重复性工作固化成一条条流程，每条流程按顺序分成若干节点，每个节点挂上这一步真正要用的文件。文件会**真正复制进数据目录**，不怕原文件移动或删除。

## 1. 安装与启动

1. 把 `HelpWork-1.1.0-portable-win64.zip` 解压到任意文件夹（如 `D:\Tools\HelpWork\`）。
2. 双击 `HelpWork.exe`，5 秒内出现三栏主界面。
3. 首次运行会在 exe 同级自动创建 `HelpWorkData\` 数据目录，全部数据都保存在这里。

> 卸载：删除程序文件夹即可，无注册表残留。备份数据 = 复制 `HelpWorkData\` 文件夹。

## 2. 界面一览

```
┌─────────────────────────────────────────────────────────────┐
│ HelpWork   [搜索框]                      [回收站] [设置]      │
├────────────┬──────────────────┬─────────────────────────────┤
│ ＋新建流程  │ 流程名    ＋添加节点 │ 节点标题（可编辑）           │
│ [筛选框]    │ ① 找素材    📎2   │ 备注（自动保存·已保存）       │
│ ▶插件制作 5│ ② 改配置    📎1   │ 附件区：拖入文件 / 添加文件   │
│  日常杂务 3 │ ③ 调脚本    📎1   │  2 个附件 · 共 3.2 MB        │
├────────────┴──────────────────┴─────────────────────────────┤
│ 📁 D:\Tools\HelpWork\HelpWorkData（点击打开）   已用 128 MB   │
└─────────────────────────────────────────────────────────────┘
```

- **左栏**：所有流程。点「＋ 新建流程」创建；右键可重命名 / 导出 / 删除；拖拽可调整顺序。
- **中栏**：当前流程的节点（步骤）。点「＋ 添加节点」创建；右键可重命名 / 上移 / 下移 / 删除；拖拽或右键调整顺序。
- **右栏**：选中节点的详情——标题、备注、附件。

## 3. 日常操作

### 3.1 建一条流程
1. 点左栏「＋ 新建流程」，输入名称（如「插件制作」），回车。
2. 中栏点「＋ 添加节点」，依次输入每一步的标题（如「找素材」「改配置」「调脚本」）。

### 3.2 给节点挂文件
- **拖拽**：把文件从资源管理器直接拖进右栏附件区。
- **选择**：点附件区「＋ 添加文件」，可一次选多个。
- 同一个文件挂到多个节点只占用一份空间（按内容自动去重）。
- 超过 500MB 的大文件导入时会有进度条，可中途取消。

### 3.3 使用文件
- **双击**附件 → 用系统默认程序打开（Word 文档开 Word，脚本开关联编辑器）。
- **右键**附件 →「在文件夹中显示」直接定位到数据目录里的实体文件。
- 右键 →「重命名显示名」只改显示名字，不影响原文件名。
- 右键 →「移除」把附件从节点上取下（进回收站，可找回）。

### 3.4 写备注
右栏备注框支持中文与换行，停止输入 0.5 秒后自动保存，显示「已保存」。关窗前未保存的内容会强制落盘。

### 3.5 搜索
顶部搜索框（快捷键 `Ctrl+F`）输入关键词，跨所有流程搜索节点标题、备注、附件名。点击结果跳到对应流程与节点，并高亮 2 秒。

### 3.6 删除与回收站
- 删除流程 / 节点都有二次确认，删除后进入**回收站**。
- 顶栏「回收站」可逐条**还原**（回到原流程）或**彻底删除**（释放磁盘空间）。
- 只有「彻底删除」才会真正移除附件文件；只要还有别的节点引用同一文件，实体就会保留。

## 4. 备份与迁移

### 4.1 备份
- 设置 →「立即备份」：把整个数据库 + 附件打包成 zip 存到 `HelpWorkData\backups\`。
- 每天第一次打开软件时自动备份一次，保留最近 7 份。

### 4.2 导出 / 导入单条流程
- 左栏流程右键 →「导出此流程」：生成 zip（含节点顺序、备注、全部附件），默认保存在 `HelpWorkData\exports\`。
- 设置 →「导入流程包」：选择导出的 zip，流程原样恢复（顺序、备注、附件内容完全一致）。

### 4.3 换电脑 / 挪数据目录
1. 把整个 `HelpWorkData\` 文件夹复制到新位置（U 盘 / 新电脑均可）。
2. 新电脑上解压程序包，启动 HelpWork。
3. 若程序没有自动找到数据：设置 →「更改数据目录」→ 浏览选择复制来的 `HelpWorkData\` 文件夹（不勾选「搬移现有数据」）。
4. 也可以勾选「搬移现有数据」把当前数据整体挪到新目录。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 启动提示「数据目录无法访问」 | 数据目录被移动或磁盘未接入。按界面提示选择新位置，或选回原目录。 |
| 双击附件没反应 | 该文件类型没有关联程序。在系统设置里给该扩展名设置默认应用。 |
| 删除了流程还能找回吗 | 24 小时内进回收站还原（回收站不会自动清空，需手动清）。 |
| 想把数据放移动硬盘 | 设置 → 更改数据目录 → 勾选「搬移现有数据」指向移动硬盘目录。 |
| 附件列表为空但记得挂过 | 检查是否切错了节点；或到回收站看是否被移除。 |

## 6. 数据目录结构（供了解）

```
HelpWorkData\
  helpwork.db          数据库（流程/节点/附件目录）
  files\               附件实体（按内容哈希存放，自动去重）
  backups\             自动/手动备份 zip（保留 7 份）
  exports\             导出的流程包
  logs\app.log         运行日志
```
